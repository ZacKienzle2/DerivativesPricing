\subsection{Random Experiments and Probability Spaces}
The basic notion in probability theory is that of a \textit{random experiment}: an experiment whose outcome cannot be determined in advance. Mathematically, a random experiment is modeled via a triplet \((\Omega, \cH, \Pm)\), where:
\begin{itemize}
	\item \(\Omega\) is the set of all possible outcomes of the experiment, called the \textit{sample space}.
	\item \(\cH\) is the collection of all subsets of \(\Omega\) to which a probability can be assigned; such subsets are called \textit{events}.
	\item \(\Pm\) is a \textit{probability measure}, which assigns to each event \(A\) a number \(\Pm[A]\) between 0 and 1, indicating the likelihood that the outcome of the random experiment lies in \(A\).
\end{itemize}
Any probability measure \(\Pm\) must satisfy the following \textit{Kolmogorov axioms}:
\begin{enumerate}
	\item \(\Pm[A] \ge 0\) for every event \(A\).
	\item \(\Pm[\Omega] = 1\).
	\item For any sequence \(A_1, A_2, \dots\) of events,
	      \begin{equation}
		      \Pm\left[ \bigcup_i A_i \right] \le \sum_i \Pm[A_i], \label{eq:SubAdditivity}
	      \end{equation}
	      with strict equality whenever the events are \textit{disjoint} (that is, non-overlapping).
\end{enumerate}

In many applications the sample space is \textit{countable}; that is, \(\Omega = \{a_1, a_2, \dots\}\). In this case the easiest way to specify a probability measure \(\Pm\) is to first assign a number \(p_i\) to each \textit{elementary event} \(\{a_i\}\), with \(\sum_i p_i = 1\), and then to define
\begin{equation*}
	\Pm[A] = \sum_{i: a_i \in A} p_i \quad \text{for all } A \subseteq \Omega.
\end{equation*}
Here the collection of events \(\cH\) can be taken to be equal to the collection of \textit{all subsets} of \(\Omega\). The triple \((\Omega, \cH, \Pm)\) is called a \textit{discrete probability space}. This idea is graphically represented in \cref{fig:DiscreteProbSpace}. Each element \(a_i\), represented by a dot, is assigned a weight (that is, probability) \(p_i\), indicated by the size of the dot. The probability of the event \(A\) is simply the sum of the weights of all the outcomes in \(A\).

\subsection{Random Variables and Probability Distributions}
It is often convenient to describe a random experiment via ``random variables'', representing numerical measurements of the experiment. Random variables are usually denoted by capital letters from the last part of the alphabet. From a mathematical point of view, a \textit{random variable} \(X\) is a function from \(\Omega\) to \(\R\) such that sets of the form \(\{a < X \le b\} \coloneqq \{\omega \in \Omega : a < X(\omega) \le b\}\) are events (and so can be assigned a probability).

A cdf \(F_c\) is called \textit{continuous}\footnote{In advanced probability, we would say ``\textit{absolutely continuous with respect to the Lebesgue measure}''.}, if there exists a positive function \(f\) such that for all \(x\)
\begin{equation}
	F_c(x) = \int_{-\infty}^x f(u) \di u. \label{eq:ContinuousCDF}
\end{equation}
Note that such an \(F_c\) is differentiable (and hence continuous) with derivative \(f\). The function \(f\) is called the \textit{probability density function} (continuous pdf). By the fundamental theorem of integration, we have
\begin{equation*}
	\Pm[a < X \le b] = F(b) - F(a) = \int_a^b f(x) \di x.
\end{equation*}
Thus, calculating probabilities reduces to integration, as illustrated in \cref{fig:ContinuousPDF}.

\subsection{Expectation}
It is often useful to consider different kinds of numerical characteristics of a random variable. One such quantity is the expectation, which measures the ``average'' value of the distribution.

The \textit{expectation} (or expected value or mean) of a random variable \(X\) with pdf \(f\), denoted by \(\E X\) or\footnote{We only use brackets in an expectation if it is unclear with respect to which random variable the expectation is taken.} \(\E[X]\) (and sometimes \(\mu\)), is defined by
\begin{equation*}
	\E X =
	\begin{cases}
		\sum_x x f(x)                      & \text{discrete case,}   \\
		\int_{-\infty}^\infty x f(x) \di x & \text{continuous case.}
	\end{cases}
\end{equation*}
If \(X\) is a random variable, then a function of \(X\), such as \(X^2\) or \(\sin(X)\), is again a random variable. Moreover, the expected value of a function of \(X\) is simply a weighted average of the possible values that this function can take. That is, for any real function \(h\)
\begin{equation*}
	\E h(X) =
	\begin{cases}
		\sum_x h(x) f(x)                      & \text{discrete case,}   \\
		\int_{-\infty}^\infty h(x) f(x) \di x & \text{continuous case,}
	\end{cases}
\end{equation*}
provided that the sum or integral are well-defined.

The \textit{variance} of a random variable \(X\), denoted by \(\Var X\) (and sometimes \(\sigma^2\)), is defined by
\begin{equation*}
	\Var X = \E(X - \E[X])^2 = \E X^2 - (\E X)^2.
\end{equation*}
The square root of the variance is called the \textit{standard deviation}. \cref{tab:ExpectationsVariances} lists the expectations and variances for some well-known distributions. Both variance and standard deviation measure the spread or dispersion of the distribution. Note, however, that the standard deviation measures the dispersion in the same units as the random variable, unlike the variance, which uses squared units.

\subsection{Joint Distributions}
Distributions for random vectors and stochastic processes can be specified in much the same way as for random variables. In particular, the distribution of a random vector \(\vecb{X} = [X_1, \dots, X_n]^\T\) is completely determined by specifying the \textit{joint cdf} \(F\), defined by
\begin{equation*}
	F(x_1, \dots, x_n) = \Pm[X_1 \le x_1, \dots, X_n \le x_n], \quad x_i \in \R, i = 1, \dots, n.
\end{equation*}

Similarly, the distribution of a \textit{stochastic process}, that is, a collection of random variables \(\{X_t, t \in \mathcal{T}\}\), for some index set \(\mathcal{T}\), is completely determined by its finite-dimensional distributions; specifically, the distributions of the random vectors \([X_{t_1}, \dots, X_{t_n}]^\T\) for every choice of \(n\) and \(t_1, \dots, t_n\).

By analogy to the one-dimensional case, a random vector \(\vecb{X} = [X_1, \dots, X_n]^\T\) taking values in \(\R^n\) is said to have a pdf \(f\) if, in the continuous case,
\begin{equation}
	\Pm[\vecb{X} \in B] = \int_B f(\vecb{x}) \di \vecb{x}, \label{eq:JointProbContinuous}
\end{equation}
for all \(n\)-dimensional rectangles \(B\). Replace the integral with a sum for the discrete case. The pdf is also called the \textit{joint pdf} of \(X_1, \dots, X_n\). The pdfs of the individual components, called \textit{marginal pdfs}, can be recovered from the joint pdf by ``integrating out the other variables''. For example, for a continuous random vector \([X, Y]^\T\) with pdf \(f\), the pdf \(f_X\) of \(X\) is given by
\begin{equation*}
	f_X(x) = \int f(x, y) \di y.
\end{equation*}

\subsection{Conditioning and Independence}
Conditional probabilities and conditional distributions are used to model additional information on a random experiment. Independence is used to model \textit{lack} of such information.

\subsubsection{Conditional Probability}
Suppose some event \(B \subseteq \Omega\) occurs. Given this fact, event \(A\) will occur if and only if \(A \cap B\) occurs, and the relative chance of \(A\) occurring is therefore \(\Pm[A \cap B] / \Pm[B]\), provided \(\Pm[B] > 0\). This leads to the definition of the \textit{conditional probability} of \(A\) given \(B\):
\begin{equation}
	\Pm[A \mid B] = \frac{\Pm[A \cap B]}{\Pm[B]}, \quad \text{if } \Pm[B] > 0. \label{eq:ConditionalProbability}
\end{equation}
The above definition breaks down if \(\Pm[B] = 0\). Such conditional probabilities must be treated with more care [11].
Three important consequences of the definition of conditional probability are:
\begin{enumerate}
	\item \textit{Product rule:} For any sequence of events \(A_1, A_2, \dots, A_n\),
	      \begin{equation}
		      \Pm[A_1 \cdots A_n] = \Pm[A_1] \Pm[A_2 \mid A_1] \Pm[A_3 \mid A_1 A_2] \cdots \Pm[A_n \mid A_1 \cdots A_{n-1}], \label{eq:ProductRule}
	      \end{equation}
	      using the abbreviation \(A_1 A_2 \cdots A_k \coloneqq A_1 \cap A_2 \cap \dots \cap A_k\).
	\item \textit{Law of total probability:} If \(\{B_i\}\) forms a partition of \(\Omega\) (that is, \(B_i \cap B_j = \emptyset, i \neq j\) and \(\cup_i B_i = \Omega\)), then for any event \(A\)
	      \begin{equation}
		      \Pm[A] = \sum_i \Pm[A \mid B_i] \Pm[B_i]. \label{eq:TotalProbability}
	      \end{equation}
	\item \textit{Bayes' rule:} Let \(\{B_i\}\) form a partition of \(\Omega\). Then, for any event \(A\) with \(\Pm[A] > 0\),
	      \begin{equation}
		      \Pm[B_j \mid A] = \frac{\Pm[A \mid B_j] \Pm[B_j]}{\sum_i \Pm[A \mid B_i] \Pm[B_i]}. \label{eq:BayesRule}
	      \end{equation}
\end{enumerate}

\subsubsection{Independence}
Two events \(A\) and \(B\) are said to be \textit{independent} if the knowledge that \(B\) has occurred does not change the probability that \(A\) occurs. That is, \(A, B\) independent \(\iff \Pm[A \mid B] = \Pm[A]\). Since \(\Pm[A \mid B] \Pm[B] = \Pm[A \cap B]\), an alternative definition of independence is
\begin{equation*}
	A, B \text{ independent} \iff \Pm[A \cap B] = \Pm[A]\Pm[B].
\end{equation*}
This definition covers the case where \(\Pm[B] = 0\) and can be extended to arbitrarily many events: events \(A_1, A_2, \dots\) are said to be (mutually) independent if for any \(k\) and any choice of distinct indices \(i_1, \dots, i_k\),
\begin{equation*}
	\Pm[A_{i_1} \cap A_{i_2} \cap \dots \cap A_{i_k}] = \Pm[A_{i_1}] \Pm[A_{i_2}] \cdots \Pm[A_{i_k}].
\end{equation*}
The concept of independence can also be formulated for random variables. Random variables \(X_1, X_2, \dots\) are said to be \textit{independent} if the events \(\{X_{i_1} \le x_{i_1}\}, \dots, \{X_{i_n} \le x_{i_n}\}\) are independent for all finite choices of \(n\) distinct indices \(i_1, \dots, i_n\) and values \(x_{i_1}, \dots, x_{i_n}\).

An important characterization of independent random variables is the following.

\begin{thm}{Independence Characterization}{IndependenceCharacterization}
	Random variables \(X_1, \dots, X_n\) with marginal pdfs \(f_{X_1}, \dots, f_{X_n}\) and joint pdf \(f\) are independent if and only if
	\begin{equation}
		f(x_1, \dots, x_n) = f_{X_1}(x_1) \cdots f_{X_n}(x_n) \quad \text{for all } x_1, \dots, x_n. \label{eq:IndependencePDF}
	\end{equation}
\end{thm}

Many probabilistic models involve random variables \(X_1, X_2, \dots\) that are \textit{independent and identically distributed}, abbreviated as \iid.

\subsubsection{Expectation and Covariance}
Similar to the univariate case, the expected value of a real-valued function \(h\) of a random vector \(\bX \sim f\) is a weighted average of all values that \(h(\bX)\) can take. Specifically, in the continuous case, \(\E h(\bX) = \int h(\bx)f(\bx)\di \bx\). In the discrete case replace this multidimensional integral with a sum. Using this result, it is not difficult to show that for any collection of dependent or independent random variables \(X_1, \dots, X_n\),
\begin{equation}
	\label{LinearityOfExpectation}
	\E[a + b_1 X_1 + b_2 X_2 + \dots + b_n X_n] = a + b_1 \E X_1 + \dots + b_n \E X_n
\end{equation}
for all constants \(a, b_1, \dots, b_n\). Moreover, for \textit{independent} random variables,
\begin{equation}
	\label{ExpectationIndependence}
	\E[X_1 X_2 \dots X_n] = \E X_1 \E X_2 \dots \E X_n.
\end{equation}
We leave the proofs as an exercise.

The \textit{covariance} of two random variables \(X\) and \(Y\) with expectations \(\mu_X\) and \(\mu_Y\), respectively, is defined as
\begin{equation}
	\label{CovarianceDefinition}
	\Cov(X, Y) = \E[(X - \mu_X)(Y - \mu_Y)].
\end{equation}
This measures the degree of linear dependency between the variables. Let \(\sigma_X^2 = \Var X\) and \(\sigma_Y^2 = \Var Y\). A scaled version of the covariance is given by the \textit{correlation coefficient},
\begin{equation}
	\label{CorrelationDefinition}
	\varrho(X, Y) = \frac{\Cov(X, Y)}{\sigma_X \sigma_Y}.
\end{equation}
The following properties follow directly from the definitions of variance and covariance.

\begin{enumerate}[1.]
	\item \(\Var X = \E X^2 - \mu_X^2\).
	\item \(\Var[aX + b] = a^2 \sigma_X^2\).
	\item \(\Cov(X, Y) = \E[XY] - \mu_X \mu_Y\).
	\item \(\Cov(X, Y) = \Cov(Y, X)\).
	\item \(-\sigma_X \sigma_Y \le \Cov(X, Y) \le \sigma_X \sigma_Y\).
	\item \(\Cov(aX + bY, Z) = a \Cov(X, Z) + b \Cov(Y, Z)\).
	\item \(\Cov(X, X) = \sigma_X^2\).
	\item \(\Var[X + Y] = \sigma_X^2 + \sigma_Y^2 + 2 \Cov(X, Y)\).
	\item If \(X\) and \(Y\) are independent, then \(\Cov(X, Y) = 0\).
\end{enumerate}

As a consequence of Properties 2 and 8 we have that for any sequence of \textit{independent} random variables \(X_1, \dots, X_n\) with variances \(\sigma_1^2, \dots, \sigma_n^2\),
\begin{equation}
	\label{VarianceOfSumIndependent}
	\Var[a_1 X_1 + a_2 X_2 + \dots + a_n X_n] = a_1^2 \sigma_1^2 + a_2^2 \sigma_2^2 + \dots + a_n^2 \sigma_n^2,
\end{equation}
for any choice of constants \(a_1, \dots, a_n\).

For random column vectors, such as \(\bX = [X_1, \dots, X_n]^\T\), it is convenient to write the expectations and covariances in vector and matrix notation. For a random vector \(\bX\) we define its \textit{expectation vector} as the vector of expectations
\begin{equation}
	\label{ExpectationVectorDefinition}
	\bmu = [\mu_1, \dots, \mu_n]^\T = [\E X_1, \dots, \E X_n]^\T.
\end{equation}
The \textit{covariance matrix} \(\bSigma\) is defined as the matrix whose \((i, j)\)-th element is
\begin{equation}
	\label{CovarianceMatrixElement}
	\Cov(X_i, X_j) = \E[(X_i - \mu_i)(X_j - \mu_j)].
\end{equation}
If we define the expectation of a vector (matrix) to be the vector (matrix) of expectations, then we can compactly write
\begin{equation}
	\label{VectorExpectationCompact}
	\bmu = \E \bX
\end{equation}
and
\begin{equation}
	\label{CovarianceMatrixCompact}
	\bSigma = \E[(\bX - \bmu)(\bX - \bmu)^\T].
\end{equation}
A useful application of the cyclic property of the trace of a matrix (see \ref{thm:CyclicProperty}) is the following.

\begin{thm}{Expectation of a Quadratic Form}{ExpectationOfQuadraticForm}
	Let \(\bA\) be an \(n \times n\) matrix and \(\bX\) an \(n\)-dimensional random vector with expectation vector \(\bmu\) and covariance matrix \(\bSigma\). The random variable \(Y := \bX^\T \bA \bX\) has expectation \(\tr(\bA \bSigma) + \bmu^\T \bA \bmu\).
\end{thm}

\begin{proof}
	Since \(Y\) is a scalar, it is equal to its trace. Now, using the cyclic property: \(\E Y = \E \tr(Y) = \E \tr(\bX^\T \bA \bX) = \E \tr(\bA \bX \bX^\T) = \tr(\bA \E[\bX \bX^\T]) = \tr(\bA (\bSigma + \bmu \bmu^\T)) = \tr(\bA \bSigma) + \tr(\bA \bmu \bmu^\T) = \tr(\bA \bSigma) + \bmu^\T \bA \bmu\).
\end{proof}


\subsection{Markov Chains}
The index \(t\) in \(X_t\) is usually seen as a ``time'' or ``step'' parameter. The index set \(\{0, 1, 2, \dots\}\) in the definition above was chosen out of convenience. It can be replaced by any countable index set. We restrict ourselves to \textit{time-homogeneous Markov chains}, Markov chains for which the conditional pdfs \(f_{X_{t+1}|X_t}(y|x)\) do not depend on \(t\); we abbreviate these as \(q(y|x)\). The \(\{q(y|x)\}\) are called the (one-step) \textit{transition densities} of the Markov chain. Note that the random variables or vectors \(\{X_t\}\) may be \textit{discrete} (e.g., taking values in some set \(\{1, \dots, r\}\)) or \textit{continuous} (e.g., taking values in an interval \([0, 1]\) or \(\R^d\)). In particular, in the \textit{discrete} case, each \(q(y|x)\) is a probability: \(q(y|x) = \Prob[X_{t+1} = y | X_t = x]\).

\begin{defn}{Markov Chain}{MarkovChainDef}
	A \textit{Markov chain} is a collection \(\{X_t, t = 0, 1, 2, \dots\}\) of random variables (or random vectors) whose futures are conditionally independent of their pasts given their present values. That is,
	\begin{equation} \label{eq:MarkovProperty}
		\Prob[X_{t+1} \in A | X_s, s \le t] = \Prob[X_{t+1} \in A | X_t] \quad \text{for all } t.
	\end{equation}
\end{defn}
In other words, the conditional distribution of the future variable \(X_{t+1}\), given the entire past \(\{X_s, s \le t\}\), is the same as the conditional distribution of \(X_{t+1}\) given only the present \(X_t\). \cref{eq:MarkovProperty} is called the \textit{Markov property}.

The distribution of \(X_0\) is called the \textit{initial distribution} of the Markov chain. The one-step transition densities and the initial distribution completely specify the distribution of the random vector \([X_0, X_1, \dots, X_t]^\top\). Namely, we have by the product rule \cref{eq:JointPdfProductRule} and the Markov property that the joint pdf is given by
\begin{align*}
	f_{X_0, \dots, X_t}(x_0, \dots, x_t) & = f_{X_0}(x_0) f_{X_1|X_0}(x_1|x_0) \cdots f_{X_t|X_{t-1}, \dots, X_0}(x_t | x_{t-1}, \dots, x_0) \\
	                                     & = f_{X_0}(x_0) f_{X_1|X_0}(x_1|x_0) \cdots f_{X_t|X_{t-1}}(x_t | x_{t-1})                         \\
	                                     & = f_{X_0}(x_0) q(x_1|x_0) q(x_2|x_1) \cdots q(x_t|x_{t-1}).
\end{align*}

A Markov chain is said to be \textit{ergodic} if the probability distribution of \(X_t\) converges to a fixed distribution as \(t \to \infty\). Ergodicity is a property of many Markov chains. Intuitively, the probability of encountering the Markov chain in a state \(x\) at a time \(t\) far into the future should not depend on the \(t\), provided that the Markov chain can reach every state from any other state, such Markov chains are said to be \textit{irreducible}, and does not ``escape'' to infinity. Thus, for an ergodic Markov chain the pdf \(f_{X_t}(x)\) converges to a fixed \textit{limiting pdf} \(f(x)\) as \(t \to \infty\), irrespective of the starting state. For the discrete case, \(f(x)\) corresponds to the long-run fraction of times that the Markov process visits \(x\).

Under mild conditions (such as irreducibility) the limiting pdf \(f(x)\) can be found by solving the \textit{global balance equations}:
\begin{equation} \label{eq:GlobalBalance}
	f(x) = \begin{cases} \sum_y f(y)q(x|y) & (\text{discrete case}), \\ \int f(y)q(x|y) \di y & (\text{continuous case}). \end{cases}
\end{equation}
For the discrete case the rationale behind this is as follows. Since \(f(x)\) is the long-run proportion of time that the Markov chain spends in \(x\), the proportion of transitions \textit{out} of \(x\) is \(f(x)\). This should be balanced with the proportion of transitions \textit{into} state \(x\), which is \(\sum_y f(y)q(x|y)\).

One is often interested in a stronger type of balance equations. Imagine that we have taken a video of the evolution of the Markov chain, which we may run in forward and reverse time. If we cannot determine whether the video is running forward or backward (we cannot determine any systematic ``looping'', which would indicate in which direction time is flowing), the chain is said to be time-reversible or simply \textit{reversible}.

Although not every Markov chain is reversible, each ergodic Markov chain, when run backwards, gives another Markov chain, the \textit{reverse Markov chain}, with transition densities \(\tilde{q}(y|x) = f(y)q(x|y)/f(x)\). To see this, first observe that \(f(x)\) is the long-run proportion of time spent in \(x\) for both the original and reverse Markov chain. Secondly, the ``probability flux'' from \(x\) to \(y\) in the reversed chain must be equal to the probability flux from \(y\) to \(x\) in the original chain, meaning \(f(x)\tilde{q}(y|x) = f(y)q(x|y)\), which yields the stated transition probabilities for the reversed chain. In particular, for a \textit{reversible} Markov chain we have
\begin{equation} \label{eq:DetailedBalance}
	f(x)q(y|x) = f(y)q(x|y) \quad \text{for all } x, y.
\end{equation}
These are the \textit{detailed} (or \textit{local}) \textit{balance equations}. Note that the detailed balance equations imply the global balance equations. Hence, if a Markov chain is irreducible and there exists a pdf such that \cref{eq:DetailedBalance} holds, then \(f(x)\) must be the limiting pdf. In the discrete state space case an additional condition is that the chain must be \textit{aperiodic}, meaning that the return times to the same state cannot always be a multiple of some integer \(\ge 2\).
